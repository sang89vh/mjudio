Requirements

  • Windows 10 version 2004 (build 19041) or later, or Windows 11
  • A 64-bit (x64) processor
  • About 215 MB of free disk space

Nothing else needs installing. The .NET runtime and the Windows App SDK are included in the download, and setup never goes online.

Installing

Run the installer and Mjudio is set up for your user account only — no administrator password is needed. It lands in %LocalAppData%\Programs\Mjudio and appears in the Start menu. To remove it, use Settings ▸ Apps ▸ Installed apps like any other program.

Windows may warn that the publisher is unrecognised, because this build is not yet code-signed. Choose More info ▸ Run anyway to continue.

Unattended install

For deployment, the installer accepts the usual silent switches:

MjudioSetup-1.0.0-x64.exe /VERYSILENT /NORESTART /SUPPRESSMSGBOXES

Earlier versions

Every release keeps its own permanent link, so an older version stays downloadable after a newer one ships. 1.0.0 is the first release.
