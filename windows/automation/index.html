Automation and AI assistants

Let a script or an AI assistant make videos with Mjudio for Windows: create a project, give it a song, set the words, render the video and save it, without touching the app window.

Updated 22 October 2026

Everything stays on your PC. Automation is off until you switch it on. When it is on, Mjudio answers only on 127.0.0.1, which is your own computer and nothing else: not your network, not the internet. Every request has to carry a token that only you can see in Settings. Nothing is uploaded anywhere; your songs, images and videos are read and rendered on your own PC.

1. Turn it on

  1. Open Mjudio and press the gear button on the Home screen to open Settings.
  2. Choose the Automation tab and tick Enable the local REST API. That one switch starts everything on this page: the API for scripts and, from version 1.0.4, the endpoint for AI assistants.
  3. The Status row then shows the address Mjudio is listening on, normally:
http://127.0.0.1:8787

The same tab has the Port (8787 unless you type another number and press Apply), the Token (Show, Copy and Regenerate; regenerating locks out every script and assistant still using the old token) and Config file ▸ Reveal, which opens the folder holding endpoint.json. Untick the switch and the server stops.

2. The address and the token

While the server runs, Mjudio writes its address and token to a file called endpoint.json. Scripts should read them from there rather than hard-code them, because the port can change. Where the file is depends on how you installed Mjudio:

  • The installer from this website, or the Microsoft Store on a PC that had the installer version first:
%APPDATA%\Mjudio\Automation\endpoint.json
  • The Microsoft Store on any other PC:
%LOCALAPPDATA%\Packages\SSGTeam.Mjudio-MusicVisualizer_ys032at6edymg\LocalCache\Roaming\Mjudio\Automation\endpoint.json

Windows keeps a Store app's new AppData folders in the app's own private copy, and only Mjudio itself sees that file at the %APPDATA% path. Settings ▸ Automation ▸ Reveal always opens the real one. This PowerShell finds the newest copy:

$endpoint = @(Get-ChildItem "$env:LOCALAPPDATA\Packages\*\LocalCache\Roaming\Mjudio\Automation\endpoint.json",
                            "$env:APPDATA\Mjudio\Automation\endpoint.json" -ErrorAction SilentlyContinue) |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
$cfg = Get-Content $endpoint.FullName -Raw | ConvertFrom-Json   # $cfg.baseURL, $cfg.token

The file is deleted when the server stops or Mjudio quits, but a crash can leave it behind. Treat a refused connection, not a missing file, as the sign that Mjudio is not running.

3. AI assistants (MCP)

From version 1.0.4, through the Microsoft Store, Mjudio also speaks the Model Context Protocol (MCP) at one more address on the same server:

http://127.0.0.1:8787/mcp

It uses the same switch, port and token as the scripting API. While the server is running, Settings ▸ Automation shows an MCP endpoint row with this address and a Copy MCP config button. The copied text contains your token, so keep it as private as the token itself, and copy it again after Regenerate or a port change. The installer on this website (version 1.0.2) has the scripting API but not this endpoint.

Mjudio answers both the current revision of the protocol (2026-07-28) and the earlier revisions that start with a handshake (2025-03-26 to 2025-11-25), so newer and older clients can both connect.

Claude Code

Tested with Claude Code 2.1.307, which then reports the server as connected. Replace YOUR_TOKEN with the token from Settings (Show, then Copy):

claude mcp add --transport http mjudio http://127.0.0.1:8787/mcp --header "Authorization: Bearer YOUR_TOKEN"
claude mcp get mjudio

Cursor, or a project's .mcp.json

This is what Copy MCP config puts on the clipboard. It is the shape Cursor's mcp.json and a Claude Code project's .mcp.json read. Not tested yet with either file; the command above was tested.

{
  "mcpServers": {
    "mjudio": {
      "type": "http",
      "url": "http://127.0.0.1:8787/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

VS Code

VS Code reads .vscode/mcp.json, which puts the same entry under a servers root. Not tested yet.

{
  "servers": {
    "mjudio": {
      "type": "http",
      "url": "http://127.0.0.1:8787/mcp",
      "headers": { "Authorization": "Bearer YOUR_TOKEN" }
    }
  }
}

Claude Desktop

Claude Desktop starts local programs from its configuration file and has no entry for an address like this one, so it needs a small local bridge program in between. That has not been tested with Mjudio for Windows yet. The Mjudio.mcpb extension on this site's downloads page does not work with the Windows app.

Use 127.0.0.1, not localhost, in every client: Mjudio listens on 127.0.0.1 only, and some clients try another address first when given localhost.

4. What to ask for

Plain requests work. An assistant needs full paths on this PC, such as C:\Users\you\Music\song.mp3, not just a file name.

  • "Make a lyric video from C:\Users\you\Music\night-drive.mp3 with a lo-fi template, in portrait 9:16 for Shorts."
  • "Change the title text to Night Drive — Test Artist."
  • "Add these lyrics to the project: …"
  • "Use C:\Users\you\Pictures\cover.jpg as the background."
  • "Export it at 1080p, wait until it finishes, and save the video to C:\Users\you\Videos."

5. What an assistant can do

AreaToolsWhat they do
Statusget_health, list_templates Whether Mjudio can render right now; the built-in templates
Projectslist_projects, get_project, create_project, update_project, delete_project List and read projects; create one from a template in 16:9, 9:16 or 1:1; rename it, change its shape, re-apply a template, trim and fade the audio; delete it
Media and textset_audio, set_artwork, set_lyrics Add the music from a file; set a full-screen background image from a file; add lyrics as plain text, .lrc or .srt text
Layersupdate_layer Rename a layer, hide or show it, change its opacity, or replace the words of a text layer
Exportscreate_export, wait_for_export, get_export, list_exports, save_export, delete_export Render an MP4 at 720p, 1080p, 1440p or 2160p (4K), 30 or 60 fps; wait for it; copy the video to a folder you choose; remove Mjudio's own copy

Layer position and size, keyframes, colours and effects are not available to an assistant: design those in a template in the app, then have the assistant apply the template. Tools that change or delete things say so, so an assistant that asks before acting will ask you first. A project that is open in Mjudio's editor can be read but not changed until you open a different project there.

6. Files and paths

  • Full local paths only, such as C:\Users\you\Music\song.mp3. A relative path is refused.
  • Network and device paths are refused (\\server\share\…, \\?\…) before Mjudio touches anything: opening a network path would make Windows offer your sign-in credentials to that computer.
  • Music: MP3, WAV, M4A, AAC or FLAC (.mp3, .wav, .wave, .m4a, .aac, .flac), up to 512 MB. Images: PNG, JPEG, BMP, GIF or TIFF, up to 512 MB.
  • Mjudio reads your file and keeps its own copy. It never changes or deletes yours.
  • Saving a video copies the finished MP4 into a folder that already exists (keeping the video's file name), or to a path ending in .mp4 whose folder exists. It replaces an existing file only if you ask for that. Mjudio keeps its own copy until delete_export removes it.

7. Scripts: the REST API

Anything an assistant does, a script can do with plain HTTP requests that carry Authorization: Bearer <token>. In PowerShell, after reading endpoint.json as shown in section 2:

$headers = @{ Authorization = "Bearer $($cfg.token)" }
Invoke-RestMethod "$($cfg.baseURL)/v1/health" -Headers $headers

The Automation API page walks through a whole video, step by step, and lists every endpoint. The requests and responses are the same on Windows, with four differences:

  • Mjudio for Windows is completely free: there are no plan limits and no watermark, so that page's section on plans does not apply.
  • endpoint.json is in the places listed in section 2, not where that page's examples look for it.
  • Music must be MP3, WAV, M4A, AAC or FLAC.
  • Videos are always written as H.264, even when a request asks for another codec.

8. A YouTube channel pipeline: auto-eliza-m

auto-eliza-m is a free, open-source kit (MIT licence) that turns a list of seed songs into long-form music videos on YouTube. It writes prompts with OpenAI, generates the tracks on Suno, has Mjudio render each track into a music-visualizer video through the automation API, merges everything with ffmpeg, and uploads the result.

seed songs  →  OpenAI  →  Suno  →  Mjudio  →  ffmpeg  →  YouTube

It comes with two pipelines: sleeppiano, a roughly two-hour instrumental piano sleep-music video, and vietcafe, chill Vietnamese café music with vocals, for which OpenAI also writes an original Vietnamese lyric. Each is resumable at every step.

What it needs, as its README lists:

  • Node.js 22.13 or newer
  • ffmpeg and ffprobe on your PATH
  • Mjudio, running, with Settings ▸ Automation switched on
  • An OpenAI API key
  • A Suno account (its Studio downloads need Suno's Premier plan) and a YouTube channel

If you installed Mjudio from the Microsoft Store on a PC that never had the installer version, add this line to the pipeline's .env file. The kit looks for endpoint.json under %APPDATA% by default, and it understands ~ in a path but not %LOCALAPPDATA%:

MVM_ENDPOINT_FILE=~/AppData/Local/Packages/SSGTeam.Mjudio-MusicVisualizer_ys032at6edymg/LocalCache/Roaming/Mjudio/Automation/endpoint.json

Start Mjudio yourself before a run as well: the kit's daily schedule script only knows how to launch the installer version.

auto-eliza-m is a separate project by the same author. It is not part of Mjudio and is not covered by Mjudio's terms. Generating and uploading content is subject to the terms of Suno, YouTube and OpenAI; use it only with accounts you own.

9. When it does not work

What you seeWhat it means
Mjudio is not answering, or the connection is refused Mjudio is not running, or Enable the local REST API is still off.
401, or the token is refused The token was regenerated. Copy the MCP config or the token again.
403 The request came from a web page, or was sent to a host name Mjudio does not accept. Use http://127.0.0.1:8787/mcp, or your own port.
project_open_in_editor That project is loaded in Mjudio's editor, which would overwrite the change. Open a different project in Mjudio, then ask again.
path_not_allowed A network path, a device path or a relative path. Give a full local path such as C:\Users\you\Music\song.mp3.
file_not_found or unsupported_audio_format Check the path, and use MP3, WAV, M4A, AAC or FLAC.
The tools never appear in the assistant Start a new conversation, or restart the assistant, after adding the server. For Claude Code, claude mcp get mjudio should say Connected.

10. Staying safe

Whatever holds the token can, through these tools, make Mjudio read any music or image file you can read, and write .mp4 files wherever you can write. That is no more than a program on your PC could already do, but an AI assistant can be steered by what it reads, such as a web page or a document. So prefer assistants that ask before running a tool, and keep the token private. If it may have leaked, press Regenerate in Settings; every script and assistant then needs the new one.
