Mjudio for Windows

Turn a song into a music visualizer or lyric video. Free, offline, and everything stays on your PC.

Mjudio for Windows is completely free. There is no subscription, no in-app purchase, no account and no sign-in, and nothing you make carries a watermark.

Download

Get it from Microsoft Store

The Microsoft Store version is signed by Microsoft, and the Store keeps it up to date.

Prefer a direct download? The installer is the same app without the Store:

  • Mjudio 1.0.2 for Windows — 64-bit installer. It is not code-signed yet, so Windows may warn that the publisher is unrecognised.

Requires Windows 10 version 2004 (build 19041) or later on a 64-bit (x64) PC. Both install for the current user only, so neither asks for administrator rights.

Before you uninstall the Store version, read where Mjudio keeps your projects.

Automation and AI assistants

Mjudio can be driven by a script, or by an AI assistant such as Claude Code: create a project, give it a song, set the words, then render and save the video. It is off until you switch it on in Settings ▸ Automation, answers only on your own PC, and needs a token for every request. The AI-assistant (MCP) endpoint arrives with version 1.0.4 through the Microsoft Store; the installer above (1.0.2) has the scripting API only. Read the guide.

Automate a YouTube channel

auto-eliza-m is a free, open-source kit (MIT licence) by the same author that turns a list of seed songs into long-form music videos on YouTube: OpenAI writes the prompts, Suno makes the tracks, Mjudio renders each one into a visualizer video, ffmpeg merges them and the result is uploaded. It is a separate project, not part of Mjudio. See how to set it up with Mjudio for Windows.
